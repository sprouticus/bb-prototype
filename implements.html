Built to Connect

Implements mount front and rear.

Towed implements run off the Catch-and-Release hitch. Front-mounted implements run off the winch. Both are add-ons, so the Enabler can carry implements front and back.

Towing Implements

With the catch-and-release added on to the vehicle, the Enabler can tow trailers, sprayers, mowers, or custom implements of your choice. All implement purchases from BB Engineering include a remote-controlled electric jack to keep the pin aligned and the driver in the seat.
